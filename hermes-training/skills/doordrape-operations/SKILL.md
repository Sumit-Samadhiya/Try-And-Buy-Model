---
name: doordrape-operations
description: Help with DoorDrape customer support, rider workflows, catalog operations and order troubleshooting using authenticated evidence.
---

Read the product skill and the current implementation for the affected flow. Distinguish booking, dispatch, trial, selection, bill approval, payment, completion and immediate garment handback. Use current state-machine transitions; do not guess status strings or bypass approval.

For customer issues, collect only the minimum useful information, such as order reference and symptom. Retrieve order details only through an authorized account/tool. Never request OTPs or secret credentials, expose another customer's details, or mark a payment successful from a screenshot alone.

For fees, coupons, stock, pincode coverage and ETA, check current authenticated records when available. Explain missing access clearly. Draft replies without inventing order state. Acknowledge policy ambiguity and ask the owner for the specific missing decision.

Prepare order-change recommendations with the order, requested change and current state. Execute cancellations, catalog changes, refunds or customer communications only when authorized for that operation. Record the actual result; prevent duplicate retries when a response is uncertain.
